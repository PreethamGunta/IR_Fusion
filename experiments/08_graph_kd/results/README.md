# `results/` — evaluation outputs

- `<name>_test.json` — locked-test evaluation for one arm or teacher. Produced
  by `graphkd.training.evaluate` (COCOeval bbox + calibration + latency).
  Fields: `AP`, `AP50`, `AP75`, `APs`, `APm`, `APl`, `per_class_AP`, `ECE`,
  `Brier`, `params`, `latency_ms`, `fps`, `weights`, `weights_sha256`,
  `split_hash`, `n_images`, `n_annotations`.
- `SUMMARY.md` — generated by `graphkd.training.summarize` from all JSONs.
- `dataset_audit.json` — split counts, class counts, RGB-crop count and the
  300-pair RGB/IR edge-registration audit.

The test split is the 609 paired frames with frame ids >= 9500. The val split
(404 frames) is used for model selection/early stopping and is never reported
as a test result.
