# WG-Fusion paper (CVPR style)

Self-contained manuscript built from the experiment artifacts.

## Files

```
paper/
├── main.tex                  # the manuscript (CVPR review style)
├── main.bib                  # references
├── cvpr.sty, ieeenat_fullname.bst   # official CVPR 2027 author-kit files
├── make_figures.py           # regenerates every data figure from artifacts
├── figures/                  # 7 generated PDFs
│   ├── fig_dataset.pdf       # val class/size/illumination stats
│   ├── fig_val_curves.pdf    # epoch-matched val curves (6 arms)
│   ├── fig_test_ap.pdf       # locked-test AP with bootstrap CIs
│   ├── fig_per_class.pdf     # per-class test AP
│   ├── fig_scale.pdf         # APs / APm / APl
│   ├── fig_oracle.pdf        # oracle recall by stratum
│   └── fig_deltas.pdf        # paired-bootstrap ΔAP forest plot
└── template/                 # downloaded author kit (reference only)
```

## Compile

A compiled review PDF is committed at `main.pdf` (7 pages), built with
[Tectonic](https://tectonic-typesetting.github.io) 0.17
(`./tectonic main.tex` — it fetches the TeX bundle on first run and needs no
local TeX installation).

Alternatively compile on Overleaf (upload the `paper/` folder, set `main.tex`
as the main document) or locally:

```bash
pdflatex main && bibtex main && pdflatex main && pdflatex main
```

`\usepackage[review]{cvpr}` produces the anonymous review version with line
numbers. Switch to `\usepackage{cvpr}` for camera-ready.

## Data provenance

Every number in the paper comes from run artifacts, not from manual entry:

| Paper element | Source |
|---|---|
| Tables 1/3 (test AP, CIs) | `results/*_test_metrics.json`, `results/bootstrap_*.json` |
| Table 2 (SOTA context) | `external/papers/NOTES.md` (venues/dates verified from the PDFs) |
| Table 3 (val best) | `runs/*/results.csv`, `runs_g2/*/results.csv` |
| Table 4 (efficiency, in text) | measured epoch times/GPU memory from run logs |
| Oracle | `results/oracle_dv_val.json` |
| Dataset stats | `results/gt/dv_v2_ir_val.json` |
| Figures | regenerated by `make_figures.py` from the above |
