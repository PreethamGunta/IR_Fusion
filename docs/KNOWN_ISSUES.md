# Known issues and limitations

## Results

1. **Single seed.** Every arm uses `seed=0`; no variance across seeds was
   measured.
2. **“100 epochs” means “up to 100 with early stopping”.** All arms use
   `patience=25`. Observed stops: CycleGAN B1 epoch 55 (best 30), CycleGAN G1
   epoch 57 (best 32), CycleDiff B1 epoch 65 (best 40).
3. **Training-time validation is clear-only.** `runs/*/results.csv` is computed
   on `yolo/train_3a/images/val` (1,635 clear frames) and is used only for
   `best.pt` selection and early stopping. The reported numbers are the frozen
   3,749-frame VTT evaluations in `results/`.
4. **CycleDiff-75 G1 is incomplete.** `runs/g1_unet_cd75_yolo12s_100` stopped at
   epoch 27/100. `last.pt` and `best.pt` exist and the filtered fog data
   (`data/filtered/unet_cd75`, 1.2 GB) is still present, so it is resumable.
   Its result JSONs do **not** exist.
5. **Older FLIR runs used a mixed test protocol** (1,200 in-domain clear frames
   vs 3,749 VTT fog frames). Do not quote their clear−fog gap. The matched
   re-score of the CycleGAN model is clear 0.16686 / fog 0.14448 mAP50-95.
6. **RT-DETR-l bench result is invalid** (29 epochs, walltime without requeue,
   mAP50-95 0.2778). Needs a rerun.
7. **CycleDiff full (100 %) model scored 0.0000.** The full-blend translation was
   unusable; only the 75 % blend is meaningful.

## Data

8. **Dangling symlinks: resolved.** The 282 links in
   `data/flir_adas_v2/synthetic/cyclediff/fog/images/train/` were re-pointed to
   the existing files in `.../fog/train_val/`. The `train_val` files were
   already referenced by the train list; the training validation set is
   `images/val` (a separate generated set), so no leak was introduced.
   Release-wide broken symlinks: **0**.
9. **`data/legacy_flir_synthetic/`** is the superseded synthetic copy. Its
   per-directory `synthetic_*.yaml` files reference splits that do not exist in
   that copy.
10. **Intermediate filtered images are not shipped.** `experiments/02_flir_gate_ir/configs/*`
   reference `data/filtered/{unet,gamma,clahe,dcp,...}`; those directories were
   deleted after the runs to save quota and are regenerated by
   `src/build_direct.py` / `scripts/run_main_100*.sh`.

## Data gaps

16. **M3FD Protocol-3B training images are not shipped.**
    `data/m3fd/3b_fog_heavy/m3fd_3b.yaml` points at
    `data/m3fd/synthetic_depth_3b/fog_heavy/...`, which is absent; only the YAML
    and `split_manifest.json` remain. The 3B result JSONs are preserved. The
    data is regenerable with `make_3b_dataset.py` from
    `data/m3fd/split` + `data/m3fd/synthetic_depth`.

17. **DSERT data is now one tree.** `data/dsert_roll` is the union of the old
    `flir_adas_experiments` copy, the M3FD method-3 copy and the
    `recover-session-12` copy: Fog, Heavy_Rain, Light_Rain, Heavy_Snow,
    Light_Snow and processed `train/`/`test/` splits. 12,400 symlinks in the
    DSERT splits were converted to relative paths.
18. **Two documentation snapshots.** Five files in
    `docs/project_notes/worktree_recover-session-12/` are newer (Oct 2026)
    than the canonical copies in `docs/project_notes/`. Both are kept; the
    canonical copy is the unsuffixed one.

## Paths and packaging

11. **Generated YAMLs contain absolute paths** to this release root
    (`configs/*.yaml`, `runs/*/args.yaml`, dataset YAMLs). They are generated by
    code that derives paths from the project root. After moving the folder, run
    `python3 scripts/relocate_paths.py --from <old> --to <new>` or regenerate.
12. **Historical shell scripts in workstream 01 are archived.** Several were
    written against the old `.kilo/worktrees/recover-session-12` checkout and
    target the pre-2026-10 layout. The current supported path is workstream 02.
13. **Secrets are excluded.** `HF_TOKEN` and `KAGGLE_TOKEN` were deliberately
    not copied. `KAGGLE_TOKEN` is also present in the old git history — rotate
    it before publishing any repository that contains that history.
14. **No git history is included.** The original `.git` (4 GB) stayed with the
    source tree; this release is a filesystem snapshot.
15. **Worktrees audited and consolidated.** `recover-session-12` (21 GB) was
    compared file-by-file against the release. Unique material was moved in:
    the full DSERT-RoLL set (including **Light_Snow, 16 GB**), `_old/`
    (187 MB), 30 sample images, the missing `gap_establishment.md`, the
    original method-1 code, two session transcripts, LPIPS weights and newer
    versions of five design docs. 1,504 byte-identical duplicate files were
    returned to the worktree to avoid duplication; nothing was deleted.
    Remaining worktree content is that duplicate set plus git metadata.
    `_trash/` was not needed and remains in the original tree.
