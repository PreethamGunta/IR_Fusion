# `configs/` — configuration index

Configs live with the experiment that uses them and are generated by the
builders; they are not versioned (see the regeneration commands below). This
directory is an index and a place for cross-experiment configuration. The
hand-written CycleDiff model configs in
`experiments/01_flir_weather_translation/method4_cyclediff/configs/` and the
environment definition `environment/environment.yml` are versioned.

| Experiment | Config location | Notes |
|---|---|---|
| 01 FLIR translation | `experiments/01_flir_weather_translation/method4_cyclediff/configs/` | CycleDiff VAE/LDM/translator YAMLs; absolute dataset paths |
| 02 GATE-IR | `experiments/02_flir_gate_ir/configs/` | 105 generated Ultralytics dataset YAMLs (`b0/b1/b2/b3/g1_*`) |
| 03 M3FD | `experiments/03_m3fd_weather/method3_cyclegan/datasets/`, `data/m3fd/**/*.yaml` | Protocol-3B and variant dataset YAMLs |
| 05 detector bench | `experiments/05_detector_bench/runs/*/args.yaml` | Frozen Ultralytics arguments per run |
| 08 graph KD | `experiments/08_graph_kd/configs/` | Generated IR/RGB/paired YAMLs and KD JSON configs |
| 09 graph fusion | `experiments/09_graph_fusion/configs/` | DroneVehicle v2, FLIR 3-class, screening and paired YAMLs |

## Regenerating the GATE-IR configs

`experiments/02_flir_gate_ir/src/*.py` builds every dataset YAML from
`src/paths.py`:

```bash
cd experiments/02_flir_gate_ir
python -m src.build_direct init      # b0/b1/b2/b3/g1 direct YAMLs
python -m src.build_datasets         # matched symlink trees + YAMLs
python -m src.build_screen           # filter-screen YAMLs
python -m src.build_cyclediff        # CycleDiff-75 YAMLs
python -m src.build_ablations        # B0/B2/B3 YAMLs
```

## Regenerating the graph-fusion configs

```bash
cd experiments/09_graph_fusion
python src/data/build_dv_v2.py --help      # DroneVehicle v2 YAMLs
python src/data/build_flir3.py --help      # FLIR 3-class YAMLs
python scripts/build_screening.py          # ⅓-train screening lists + YAMLs
```

Generated YAMLs contain absolute paths (an Ultralytics requirement); the
generating code derives them from the repository root. Regenerate them if the
checkout location changes.
